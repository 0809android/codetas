# Security policy

## Reporting a vulnerability

Report vulnerabilities privately through GitHub's
[private vulnerability reporting](https://github.com/0809android/codetas/security/advisories/new)
("Report a vulnerability" on the repository's Security tab). Do not open a
public issue for a vulnerability, and do not include credentials, private
project instructions, transcripts, or memory data in any report.

CODETAS is pre-alpha. Reports are handled on a best-effort basis.

The current trust model and security guarantees are documented in
[`docs/SECURITY.md`](docs/SECURITY.md).
