# CODETAS bundle icon source

`codetas-mark-1024.png` is rendered from `apps/web/public/codetas-mark.svg`, which is the same mark shown at the top-left of the CODETAS window.

Do not pass `icons/icon.png` back to `tauri icon`: that file is an output generated by Tauri and using it as the input causes an in-place overwrite. Regenerate from the source file instead:

```bash
magick apps/web/public/codetas-mark.svg -background none -resize 1024x1024 apps/desktop/src-tauri/icons/source/codetas-mark-1024.png
npx tauri icon apps/desktop/src-tauri/icons/source/codetas-mark-1024.png
```
